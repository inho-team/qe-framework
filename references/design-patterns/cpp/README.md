# C++ 디자인 패턴

빌드에서 언어 표준, 예외와 RTTI 사용 여부, 동적 할당 제약을 확인한다. 설계 전에 자원의 소유자와 객체의 수명을 파악하고, 공개 헤더와 바이너리 인터페이스를 사용하는 모듈을 확인한다. 이 목차의 예시는 C++17을 기준으로 하며, 예외가 필요한 예시는 해당 전제를 밝힌다.

예시의 `&& ./demo` 명령은 POSIX 셸 기준이다. Windows PowerShell 5에서 Windows용 GCC를 사용한다면 컴파일 명령의 출력 파일을 `-o demo.exe`로 지정하고, 컴파일이 성공한 뒤 `.\demo.exe`를 실행한다.

| 패턴 | 선택 기준 |
| --- | --- |
| [RAII](raii.md) | 자원 획득과 반환을 객체의 수명에 묶어 여러 종료 경로에서 같은 정리 계약을 적용한다. |
| [Strategy](strategy.md) | 호출 코드를 유지하면서 알고리즘이나 동작을 실행 중에 선택한다. |
| [Policy-based design](policy-based-design.md) | 객체의 타입을 정할 때 동작도 고정하고 구체 연산의 인라인화를 허용한다. |
| [Adapter](adapter.md) | 외부 타입과 C API의 호출 방식, 오류 또는 소유권을 내부 계약으로 바꾼다. |
| [Factory](factory.md) | 설정과 입력에 따라 제품의 타입이나 초기화 과정을 선택한다. |
| [Pimpl](pimpl.md) | 공개 헤더에서 구현 타입과 구현 전용 의존성을 숨긴다. |
| [Visitor](visitor.md) | 닫힌 타입 집합에 출력, 집계 등 여러 연산을 따로 정의한다. |
