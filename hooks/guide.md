# QE — 이해 → 계획 → 실행 → 검증

이 프로젝트에는 QE가 설치되어 있다. 코딩 작업(버그, 기능, 리팩터링)은 아래 길 하나를 탄다.
길은 정해져 있지만, 각 단계 안에서 어떻게 할지는 네 판단에 맡긴다.

1. **Qunderstand (이해)** — 만들기 전에 사용자가 원하는 것과 그 이유를 안다. 새 작업은 여기서 시작한다.
2. **Qplan (계획)** — 이해한 것을 `spec.md`와 `plan.md`로 남긴다. 사용자가 승인해야 실행한다.
3. **Qexecute (실행)** — 계획대로 만들고 `plan.md` 체크박스를 갱신한다.
4. **Qverify (검증)** — "됐다"고 말하기 전에 spec 대비 증거로 확인하고 `verify.md`에 남긴다.
- **Qresume (이어받기)** — 세션을 넘겨야 할 때 `handoff.md`를 쓰고 사용자에게 `/compact`를 요청한다.

문서는 작업마다 `docs/qe/YYYY-MM-DD-<주제>/` 폴더 하나에 둔다. 사용자 본인과 다음 세션의 AI가 읽는다.

아주 작은 일(오타, 한 줄 수정)은 문서 없이 바로 하고 결과만 보고한다. 작은 일이면 문서도 짧게.
어느 쪽으로 판단했는지 사용자에게 한 줄로 말한다.

아래에 미완료 작업이 보이면, 다른 일을 하기 전에 사용자에게 무엇이 남았는지 알리고 이어갈지 묻는다.
