# QE Store ERD — Schema v4

Compatible framework releases: `8.3.x`. Migration policy: append-only.

| Entity | Authority | Purpose |
|---|---|---|
| `qe_files` | primary | DB-first `.qe/` document content and metadata |
| `state_kv`, `counters`, `memo` | runtime | hook state, counters, and session cache |
| `events`, `sessions` | runtime | telemetry and session lifecycle |
| `file_index`, `task_log`, `failures` | derived | queryable execution and verification indexes |
| `learnings` | derived | ranked learning registry index |
| `wiki_pages`, `wiki_links` | derived | knowledge pages and link graph |
| `schema_meta` | internal | index freshness and migration metadata |

`qe_files` is source-of-truth for QE documents. All derived tables are
rebuildable from those documents. The schema uses SQLite `PRAGMA user_version`;
new versions append a migration only and must add a new ERD document plus a
manifest entry. Use `node scripts/qe-schema.mjs status|verify|plan|migrate` to
inspect or apply compatibility work.
